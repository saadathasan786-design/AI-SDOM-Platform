# Validation Tests

The generated project must provide executable checks appropriate to its selected stack.

Minimum validation areas:

- required project files and directories;
- configuration schema validity;
- navigation integrity;
- responsive layout checks;
- accessibility checks;
- metadata and heading hierarchy;
- missing/invalid content placeholders;
- broken asset references;
- runtime/build errors.

Passing the boilerplate baseline does not constitute production acceptance of a generated project.
